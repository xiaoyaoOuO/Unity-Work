# 软件配置与运维文档

## 1. 配置管理
- 采用Git进行源代码、资源、配置文件的版本管理。
- 重要配置（如存档路径、资源加载路径）通过统一配置文件管理，便于环境切换。

## 2. 版本控制
- 主分支仅用于发布稳定版本，开发分支用于日常开发，特性分支用于新功能开发。
- 每次发布前打Tag，便于回溯和回滚。

## 3. 持续集成（CI）
- 推荐配置CI工具（如GitHub Actions），自动完成以下任务：
  - 拉取最新代码
  - 自动编译、打包
  - 运行单元测试
  - 生成构建报告

## 4. 部署与运维计划
- 构建产物通过CI自动上传至云盘或服务器，便于团队成员获取。
- 生产环境与测试环境分离，避免测试影响正式版本。
- 定期备份存档和重要数据，防止数据丢失。
- 监控日志（如Unity日志、崩溃日志），及时发现和修复线上问题。

## 5. 运维工具与流程
- 使用Unity Cloud Build等工具可实现云端自动构建。
- 通过脚本自动化资源导入、打包、分发流程，减少人工干预。
